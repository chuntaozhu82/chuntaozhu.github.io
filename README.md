# 朱春涛个人网站

## 网站简介

这是朱春涛的个人官方网站，展示其作为投资人的职业经历、投资案例和投资理念。

## 网站特点

- 现代简洁的设计风格
- 完全响应式布局（支持桌面、平板、手机）
- 平滑滚动和动画效果
- 交互式导航和表单

## 技术栈

- HTML5
- CSS3（Flexbox + Grid布局）
- 原生JavaScript（无需任何框架）
- Google Fonts（Noto Sans SC）

## 文件结构

```
webset/
├── index.html      # 主页面
├── styles.css      # 样式文件
├── script.js       # 交互脚本
└── README.md       # 说明文档
```

## 本地预览

直接在浏览器中打开 `index.html` 文件即可预览网站。

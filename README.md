# 朱春涛个人网站

## 网站简介

这是朱春涛的个人官方网站，展示其作为投资人的职业经历、投资案例和投资理念。

## 网站特点

- 现代简洁的设计风格
- 完全响应式布局（支持桌面、平板、手机）
- 平滑滚动和动画效果
- 交互式导航和表单

## 技术栈

- HTML5
- CSS3（Flexbox + Grid布局）
- 原生JavaScript（无需任何框架）
- Google Fonts（Noto Sans SC）

## 文件结构

```
webset/
├── index.html      # 主页面
├── styles.css      # 样式文件
├── script.js       # 交互脚本
└── README.md       # 说明文档
```

## 本地预览

直接在浏览器中打开 `index.html` 文件即可预览网站。

## 部署说明

### GitHub Pages 部署

1. 创建GitHub仓库
2. 上传所有文件到仓库
3. 在仓库设置中启用 GitHub Pages
4. 选择分支（main/master）和文件夹（root）

### Cloudflare Pages 部署

1. 登录 Cloudflare Dashboard
2. 进入 Pages 页面
3. 连接 GitHub 仓库
4. 配置构建设置（无需构建命令）
5. 部署

## 自定义修改

- **个人信息**：编辑 `index.html` 中的文本内容
- **样式颜色**：修改 `styles.css` 中的 CSS 变量
- **联系方式**：更新联系区域的邮箱和社交链接
